# Eudemons Online Server Base

Welcome to this customized **Eudemons Online** server source package. 

> [!NOTE]
> This source is **not** a complete server solution, but it serves as a solid foundation and starting point for anyone interested in server development, learning the codebase, or building their own custom server setup.

---

## 🚀 Overview & Features

While this project is built on an existing base source, significant effort has been invested into fixing bugs and enhancing stability:

- **Source Code Enhancements:** Extensive bug fixes, modifications, and core improvements applied across the base source code.
- **Development Base:** Ideal starting point for debugging, refactoring, and developing custom features.

---

## 🛠️ Project Status & Development Notes

- **Completeness:** Development base / Work-in-Progress (WIP).
- **Intended Audience:** Server developers, modders, and reverse engineers.
- **Requirements:** C# development environment for source compilation and standard database setup. MySQL 8 for running the database
